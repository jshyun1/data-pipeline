설계 포인트 — 인포매티카 모니터 참고
1

커튼형 현황 요약

펼치면 지금 카드 그대로(누르면 목록이 좁혀지는 동작 포함). 접으면 한 줄 요약만 남고 실패 수는 빨간 숫자로 계속 보인다. 접힘 상태는 브라우저에 기억해 다음에도 유지.

2

네비게이터 트리 (유지)

지금 트리 구조·검색·우클릭 메뉴·«조치» 표시 그대로. 제안: 이름 앞에 오늘 마지막 실행 상태 점(인포매티카 Navigator 의 상태 아이콘) - 트리만 훑어도 어디가 실패인지 보인다.

3

컨텍스트 바

지금 보는 범위(경로) · 보기 방식 · 기간 · 상태 필터 · 검색을 목록 위 한 줄에. 기본 기간은 지금처럼 «오늘». 실행 이력 창에만 있던 기간 선택(오늘/7일/30일)을 여기로 올려 팝업 없이 과거 실행도 같은 표에서 본다.

4

실행 목록 = 인포매티카 Task View

한 표에서 워크플로우 실행 → (하위 워크플로우 호출) → Job → 단계 순서로 펼친다. 지금은 가운데 목록(오늘 마지막 실행 1줄) · 아래 Task 표 · 실행 이력 팝업이 따로였는데 하나로 합쳤다. 실행이 여러 번이면 실행마다 한 줄. 실패 경로는 기본으로 펼쳐 둔다. 행 끝 동작(로그 · 이 작업만 실행 · 이 작업부터 실행)은 마우스를 올리거나 실패 행이면 보인다.

5

타임라인 = Gantt Chart View

같은 데이터를 시간축으로. 워크플로우와 Job 이 언제·얼마나·겹쳐서 돌았는지, 선행 실패로 못 돈 구간(빗금)이 한눈에 보인다. 막대를 누르면 목록과 같이 아래 상세가 바뀐다.

6

하단 상세 창 = Properties 창

오른쪽 좁은 속성창(320px) 대신 목록 아래 넓은 창(높이 끌어서 조절 · 접기 가능). 탭: 요약 · 작업/단계 · 로그 · 실행 이력 · 알림 규칙 · 속성. 실패 로그 창 · 실행 이력 창 · DAG 상세 창이 전부 탭으로 들어와 팝업이 없어진다. 실행 설정(배포/시작/중지/감시 재개)은 상세 머리의 메뉴 버튼.
